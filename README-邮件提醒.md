# 新设备登录邮件提醒 + 换绑（Pro 6.24 / 6.25）

账号在一台新设备上登录时，系统会发邮件到这个账号绑定的「提醒邮箱」。

- 手机号注册的账号：进入系统后会弹窗问要不要绑定邮箱，输入邮箱 → 收 6 位验证码 → 确认绑定。
- 邮箱注册的账号：在「工作台设置 → 登录邮件提醒」里一键用登录邮箱开启。
- 每台新设备只提醒一次。

## 换绑手机号 / 邮箱（6.25）

在「工作台设置 → 换绑手机号 / 邮箱」里操作，都需要输入当前密码。

- **换绑手机号**：没有短信验证，请仔细核对号码。
- **换绑或绑定登录邮箱**：验证码会发到新邮箱，所以要先配好发信邮箱。手机号注册的账号绑定邮箱后，用手机号或邮箱都能登录。

换绑成功后，系统会发邮件通知旧的登录邮箱和提醒邮箱，管理后台的「日志」里也会留下记录。

## 为什么要自己配置发信邮箱

Supabase 自带的邮件服务只会发给项目团队成员的邮箱，发不到普通用户的邮箱。所以这个功能由 Edge Function `login-alert-mail` 用你自己的邮箱通过 SMTP 发信。

发信邮箱的账号和授权码只放在 Supabase 服务端（Edge Function Secrets），不会出现在网页里，也不在仓库里。**不要把授权码发到聊天里。**

## 需要做的事

1. **执行 SQL**：在 Supabase 的 SQL Editor 里执行
   - `supabase/v6_23_login_alerts.sql` 的第 2 段（如果还没执行），
   - `supabase/v6_24_login_alert_email.sql`。期望结果是 tables = 2、service grants = 3、client blocked = 2、rebind columns = 6。
2. **拿 QQ 邮箱授权码**：
   1. 打开 QQ 邮箱网页版，进入「设置 → 账号与安全 → 安全设置」，开启「POP3/IMAP/SMTP 服务」。
   2. 按提示用手机验证后会得到一串**授权码**。授权码不是 QQ 密码。
3. **填进 Supabase**：打开 Supabase 后台，进入 Edge Functions → Secrets，添加下面两条：
   - `SMTP_USER` = 发信的 QQ 邮箱地址（例如 xxx@qq.com）
   - `SMTP_PASS` = 上一步拿到的授权码

   下面三项可以不填：
   - `SMTP_HOST`：qq.com、foxmail.com、163.com、126.com 的邮箱会自动识别。
   - `SMTP_PORT`：只能是 465。Supabase 不允许使用 25 和 587 端口。
   - `SMTP_FROM_NAME`：发件人名称，默认是「售后雷达」。

## 限制

- 提醒是由新设备上的网页触发的，这一点和设备注册一样。懂技术的人如果绕过网页直接调用接口，就不会触发提醒。
- 设备 ID 存在浏览器里。清除浏览器数据之后，这台设备会被当成新设备，因此也会收到一封提醒。
- QQ 邮箱对每天的发信量有限制，个人使用一般够用。
