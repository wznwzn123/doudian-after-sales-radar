# QQ 群机器人用的动画表情包

来源：Google Noto Emoji 动画版（Noto Animated Emoji，https://googlefonts.github.io/noto-emoji-animation/ ），许可 CC BY 4.0（https://creativecommons.org/licenses/by/4.0/ ），作者 Google。
本目录的文件是从 fonts.gstatic.com 下载的 512px GIF 缩小到 120×120、最多 30 帧、64 色并铺白底后的版本（属于修改后的版本）。
只有常见表情和手势，没有文字、人物肖像、政治或不适宜内容。

AI 回复里写 `[表情:名字]`，名字和文件的对应在 `supabase/functions/qqbot-chat/lib.ts` 的 STICKERS 里；手机脚本从 GitHub Pages 下载一次后缓存在脚本目录。
